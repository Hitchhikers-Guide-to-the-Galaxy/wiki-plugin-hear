Hear Crowds outside the wiki

The plugin bundle is loaded from atlas.anarchive.earth; the map, voices and policy from its assets. Edit the item text and press Mount. Serve this file over http (for example python3 -m http.server 8080 in this folder) so the MODULE line can load a local file and the wiki's CORS answers a real origin.

— then open the console: window.hear is the engine (hear.sound.emitters, hear.sound.setChain(fn), hear.policy, hear.world.ctl.pos).
